Roblox development tools

roblox-studio [PLACE.rbxl or PLACE.rbxlx] opens Studio through Vinegar.
roblox-studio-settings opens Vinegar settings.
roblox-studio-mcp runs the MCP bridge of the newest installed Studio over stdio
with Vinegar's Wine, outside the Flatpak sandbox, for MCP clients.
blender launches the Blender Flatpak.
roblox-rojo-serve [PROJECT] [PORT] starts Rojo on localhost only.
roblox-build [PROJECT] [OUTPUT] defaults to ~/roblox-builds, outside the project.
roblox-nvim [FILES] uses the existing Neovim setup with additional Luau support.
roblox-sourcemap [PROJECT] [--watch] keeps generated maps under ~/.cache.
roblox-dev-check and roblox-dev-diagnose report the installation state.

Tool pins are recorded in rokit-tools.toml. Keep project pins equal to them:
Spell's scripts check exact versions. No game is created, copied, opened or
served by setup. Sign into Studio separately on each PC.

On NixOS, Home Manager links luau-lsp, lune, rojo, selene, stylua and wally in
~/.local/bin to the pinned Nix builds. Project rokit, aftman and foreman
manifests are not consulted for these six commands, and rokit install does not
change what they run, so other pins, such as rojo 7.4 or the Quenty forks in
RESOURCE_LIBRARY, are not honoured. Rokit itself stays installed. Activation
reinstalls the Rojo 7.7.1 Studio plugin whenever it differs. The Luau parser,
API docs and Roblox type definitions are linked under ~/.local/share/roblox-dev;
the types come from luau-lsp commit 7a10f6d2, whose SHA-256 Spell's typecheck
verifies.

Studio configuration is seeded from ~/.config/roblox-dev/vinegar.toml only if
absent. Its virtual desktop contains Wine dialogs; browser login is enabled.
Blender and Vinegar can use ~/dev/roblox and ~/roblox-builds. Setting up these
permissions does not create or copy the game directory.

On other distributions the six commands are wrappers around Rokit shims in
~/.rokit/bin, so Rokit picks each version from the nearest project manifest and
falls back to the global one. Install Rokit 1.2.0 from its official release,
copy rokit-tools.toml to ~/.rokit/rokit.toml, then trust and install the tools:
  cd ~/.rokit
  rokit trust rojo-rbx/rojo Kampfkarren/selene UpliftGames/wally lune-org/lune JohnnyMorganz/luau-lsp JohnnyMorganz/StyLua
  rokit install
Install the Blender and Vinegar Flatpaks, matching Rojo Studio plugin and Luau
parser as well. Keep account data and credentials outside this package.
